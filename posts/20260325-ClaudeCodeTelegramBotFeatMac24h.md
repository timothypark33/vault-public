안녕하세요. 최근 핫한 **Claude Code**를 MCP(Model Context Protocol)로 **텔레그램 봇**에 붙이려다 겪은 시행착오와, “맥북을 24시간 서버처럼” 돌리기 위한 **타협(?)**까지 한 번에 정리해 봤습니다.  
저처럼 *“내 맥북에서 봇만 계속 돌리고 싶은데…”* 하시는 분께 도움이 되길 바랍니다.

> **보안 한 줄:** Bot API 토큰은 절대 글/스크린샷/Github에 올리지 말고, 터미널·환경 변수·키체인 쪽에서만 다루세요. 유출되면 BotFather에서 즉시 revoke 후 재발급이 안전합니다.

---

## 1단계: 텔레그램 MCP 서버 연결하기

Claude Code에 텔레그램 “날개”를 달아 주는 순서입니다.

1. **Bun 설치** (MCP 서버가 Bun 기반인 경우가 많음)

   ```bash
   curl -fsSL https://bun.sh/install | bash
   ```

2. **BotFather**  
   텔레그램에서 `@BotFather` → `/newbot` → 봇 이름·유저네임 설정 후 **API Token**을 받는다.

3. **플러그인 설치·설정** (Claude Code 세션에서)

   ```text
   /plugin install telegram@claude-plugins-official
   /telegram:configure [내_토큰]
   ```

4. **재실행 (중요)**  
   설정만 하고 일반 `claude`만 치면 채널이 안 열릴 수 있다. 안내에 나온 대로 **`--channels plugin:telegram...`** 형태의 플래그를 붙여 다시 실행해야 봇이 깨어난다.

---

## 2단계: “왜 답장이 없지?” (첫 번째 삽질)

설정은 끝났는데 봇 DM에 묵묵부답일 때의 체크리스트입니다.

| 의심 지점 | 할 일 |
|-----------|--------|
| `--channels` | 단순 `claude`만 실행하지 않았는지 확인 |
| Linux(Ubuntu) | `bun` PATH, 방화벽, `curl`로 Telegram API 연결 여부 |
| 페어링 | 봇에게 먼저 말을 걸고, 받은 **6자리 코드**를 터미널에서 처리 (접근 정책은 공식 스킬/문서 기준) |

환경마다 메시지가 조금씩 다르니, **공식 플러그인 안내**와 터미널 로그를 같이 보면 수월합니다.

---

## 3단계: 맥북을 서버로? “비밀번호 벽”

봇 동작은 확인했는데 현실 문제는 하나였습니다.

> **내가 자거나 나가면 맥이 꺼지거나 잠들면 → 프로세스도 같이 멈춘다.**

- **시도:** `pmset`으로 아침 자동 기동  
  `sudo pmset repeat wakeorpoweron MTWRFSU 09:00:00`
- **좌절:** 맥북은 **FileVault(전체 디스크 암호화)** 때문에 부팅 직후 **로그인 화면에서 멈춤**. 로그인 전에는 원하는 데몬/터미널 세션이 안 올라오는 경우가 많아, “봇만 덜렁 돌아가게” 만들기가 생각보다 빡세다.

스케줄 깨우기 자체에 대한 정리는 여기 글에 더 적어 두었습니다: [HowToWakeMacAutomatically](./20260325-HowToWakeMacAutomatically.md).

---

## 4단계: 최종 타협 — “잠들지 않는 맥북 + 크램쉘”

결론은 직설적이었습니다.

> **끄지 말고, 덮개만 닫아서 돌려 두자.**

- **도구 예시:** **Theine**, **Amphetamine** 등 “잠자기 방지 / 깨어 있게 유지” 앱.
- **실전 루틴**
  1. 전원 어댑터 연결 (발열·배터리 스트레스 줄이기).
  2. 잠자기 방지 앱으로 **슬립 방지**를 켠다.
  3. Claude Code + 텔레그램 채널 세션을 실행한다.
  4. **덮개를 닫는다 (클램셸/크램쉘 모드).**

화면은 꺼지고 본체는 계속 돌아가니, 전기·판넬 수명은 신경 쓰되 “24시간 DM에 답하는 봇” 목적에는 잘 맞는 편입니다. (장시간 가동은 통풍·먼지·온도만 챙기면 됩니다.)

---

## 요약

1. **Claude Code + Telegram MCP** 조합은 강력하다.
2. 설정 후에는 **`--channels`** 로 채널까지 열었는지 꼭 확인.
3. 맥북만으로 “무인 서버”를 노리면 **FileVault·로그인 세션** 벽이 있다. 당장 실용적인 루트는 **잠자기 방지 + 전원 연결 + 덮개 닫기** 쪽이 정신 건강에 이롭다.

이제 텔레그램만 열면 이동 중에도 “나만의 AI 코딩 비서”와 대화할 수 있게 됩니다. 비슷한 삽질 중이면 편하게 댓글(또는 DM) 주세요.
