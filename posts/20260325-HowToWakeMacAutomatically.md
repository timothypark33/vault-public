Mac을 **매일 아침 특정 시각에 켜고(또는 깨우고), 밤에 끄거나 재시작·잠자기** 같은 전원 일정을 맞추고 싶을 때 macOS에는 `pmset`이라는 전원 관리 도구가 있다. 여기서는 가장 흔한 패턴인 **반복 스케줄(`pmset repeat`)** 기준으로 정리한다.

## 전제: 관리자 권한과 보안

- `sudo`가 붙는 명령은 **관리자 암호**가 필요하다. 터미널에서 암호를 입력할 때 **화면에 글자가 안 보이는 것은 정상**이다. 입력 후 Enter만 누르면 된다.
- 회사/학교 장비라면 **IT 정책**과 충돌할 수 있으니 사전 확인이 좋다.
- 노트북은 모델·설정에 따라 **전원 어댑터 연결**, **뚜껑(리드) 닫힘**, **배터리 잔량**에 따라 깨우기 동작이 달라질 수 있다. 데스크톱 Mac은 상대적으로 예측 가능하다.

## 요일 코드 (repeat에 사용)

| 코드 | 요일 |
|------|------|
| M | 월요일 |
| T | 화요일 |
| W | 수요일 |
| R | 목요일 |
| F | 금요일 |
| S | 토요일 |
| U | 일요일 |

`MTWRFSU`는 **월~일 매일**을 의미한다.

## 매일 아침 8시: 켜기 또는 깨우기

맥이 **완전히 꺼진 상태**에서도 켜지게 하려면(지원되는 하드웨어 한정) `wakeorpoweron`을 쓴다.

```bash
sudo pmset repeat wakeorpoweron MTWRFSU 08:00:00
```

- **의미**: 지정한 요일·시각에 **시스템 기동 또는 절전에서 깨우기**를 시도한다.
- **이미 켜져 있고** 화면만 잠긴 경우에는 “깨우기”에 가깝게 동작하는 경우가 많다.
- **완전 종료 후**에도 켜지게 하려면 해당 Mac이 **스케줄 기상(power on)을 지원**해야 한다. 지원 여부는 기종·OS·설정에 따라 다르다.

## 매일 밤 11시: 끄기 (종료)

```bash
sudo pmset repeat shutdown MTWRFSU 23:00:00
```

- **의미**: 지정 시각에 **시스템 종료**를 예약한다.
- 실행 중인 앱은 종료 절차에 따라 **저장하지 않은 작업**이 있으면 문제가 될 수 있으니, 중요한 작업은 미리 저장하거나 백그라운드 작업 스케줄을 조정하는 것이 안전하다.

### 깨우기만 하고 잠자기로 두고 싶다면

종료 대신 **절전**이나 **디스플레이만 끄기** 등은 목적에 맞게 다른 `pmset`/`caffeinate` 전략을 쓰는 편이 낫다. “매일 23시에 반드시 전원 OFF”가 아니라면 종료 대신 절전 스케줄을 검토해 볼 수 있다.

## 현재 스케줄 확인

```bash
pmset -g sched
```

- **반복 스케줄**과 OS/하드웨어가 보고하는 **다음 전원 이벤트**를 확인하는 데 쓴다.
- 출력이 없거나 기대와 다르면 `sudo` 없이 확인되는 항목과, 관리자로 설정한 항목이 분리되어 보일 수 있으니 맥락을 같이 본다.

## 모든 예약 삭제 (repeat 초기화)

```bash
sudo pmset repeat cancel
```

- 이후 `pmset -g sched`로 비어 있는지 확인하면 된다.

## 자주 묻는 점과 주의사항

1. **왜 아침에 안 켜질까?**  
   - 전원 코드 미연결(노트북), 에너지 절약 옵션, “네트워크 액세스로 깨우기” 등 다른 설정과의 상호작용, 또는 해당 기종이 **완전 꺼짐에서의 자동 기상**을 지원하지 않을 수 있다.

2. **저녁 shutdown과 아침 wake를 같이 쓸 때**  
   - 하나의 `repeat` 라인으로 여러 이벤트를 섞는 방식보다, **요구사항에 맞게 각각 설정**하고 `pmset -g sched`로 최종 상태를 확인하는 습관이 좋다. (환경에 따라 문서와 실제 동작 표현이 달라 보일 수 있어, 설정 후에는 반드시 **하루~이틀 시험**이 안전하다.)

3. **시간대**  
   - 스케줄은 보통 **시스템 로컬 타임** 기준으로 해석된다. 여행·서머타임 변경 시 재점검하자.

4. **자동 백업·Obsidian Sync·Git push**  
   - “켜지자마자” 클라우드/네트워크가 올라오기까지 **수십 초~수분** 걸릴 수 있다. 스크립트나 `launchd` 작업은 **네트워크 준비 이후** 실행되도록 여유를 두는 편이 안정적이다.

## 한 줄 요약

- **아침 8시 기동/깨우기**: `sudo pmset repeat wakeorpoweron MTWRFSU 08:00:00`  
- **밤 11시 종료**: `sudo pmset repeat shutdown MTWRFSU 23:00:00`  
- **확인**: `pmset -g sched`  
- **초기화**: `sudo pmset repeat cancel`  

설정 후에는 **실제 하루를 돌려 보며** 깨우기·종료가 기대대로인지 확인하고, 노트북은 **전원 연결 여부**까지 같이 점검하는 것을 권장한다.
